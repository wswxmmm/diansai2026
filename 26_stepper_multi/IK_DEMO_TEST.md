# 无限位开关低速逆解演示

## 默认参数

- 基座坐标目标：X=200 mm，Y=0 mm，Z=0 mm。
- X/Y/Z表示磁铁吸附接触点；Z轴向上。
- 控制坐标把底座落地面设为Z=0，肩轴高度约130.2 mm。
- 连杆：120+120 mm。
- 腕轴到工具轴水平偏置：53 mm。
- 磁铁竖直长度暂定：30 mm。
- 三轴传动：GT2 16T→90T，5.625:1，50脉冲/机械度。
- 电机速度：2 RPM；Emm加速度参数：5。
- 实机方向修正：地址2下臂方向异或为1，地址3上臂方向异或为0。
- 无回零开关演示保护：每次按键只推进一个最大轴角不超过5°的小段。

## 默认解算结果

机械臂上电时必须人工摆在用户指定的初始姿态：

- 底座：0°。
- 下臂绝对角：90°，即竖直向上。
- 上臂绝对角：0°，即水平向外。

默认坐标解算为：

- 底座：0.000°，总变化0°，0脉冲。
- 下臂：约7.882°，总变化约-82.118°，约4106脉冲。
- 上臂：约-76.441°，总变化约-76.441°，约3822脉冲。

目标点的腕轴坐标约为半径147 mm、高度30 mm；磁铁再向下30 mm，吸附面到达Z=0。两段连杆没有完全伸直，解算余量充足。

## 按键动作

1. 上电只使能并停止三轴，不会自动运动。
2. 每按一次PB21，下臂和上臂同步推进一个小段，最大轴角为5°；向地面点推进时PB22闪1次。
3. 约17次按键后到达X=200、Y=0、Z=0。之后每按一次向初始姿态返回一段，PB22闪2次。
4. 再约17次回到下臂竖直、上臂水平，随后重新进入下降过程。
5. PB22闪5次表示目标不可达、分段保护失败或UART发送失败。

## 重要限制

- 机械臂没有限位开关和位置回读，代码中的“当前位置”只是软件累计值。
- 烧录并复位前，必须人工把下臂放为竖直向上、上臂放为水平向外；否则软件角度与实物不一致。
- 第一次只按一次，随时准备切断驱动器电源。闭环电机运动时不要用手阻挡。
- 默认磁铁长度和坐标仍是占位值，本次只验证逆解方向与联动关系，不执行真实吸球。
