# 26_stepper_multi：三轴机械臂 + 树莓派钢球视觉伺服

本工程已经把三轴 Emm 闭环步进驱动、机械臂正/逆运动学，以及天猛星和
Raspberry Pi 的双向 UART 通信整合到同一固件中。

## 硬件分配

| 功能 | 天猛星外设和引脚 | 参数 |
|---|---|---|
| 三台 Emm 驱动器总线 | UART0，PA10 TX / PA11 RX | 115200，地址 1/2/3 |
| Raspberry Pi 通信 | UART3，PB12 TX / PB13 RX | 115200 |
| 板载按键 | PB21 | 仅在位姿已确认且视觉关闭时运行旧 IK 测试 |
| 板载 LED | PB22 | 移动时翻转；视觉到位后常亮 |

电机地址 1 是底座、地址 2 是下臂、地址 3 是上臂。最新实机测试确认底座和
下臂方向需要反相，上臂不反相；三轴传动均按 16 齿电机轮带 90 齿输出轮
（5.625:1）计算。

## 视觉控制安全逻辑

- 上电绝不自动运动，也不再假定固定关节初始角。
- 操作者只需把相机放在离地约 10～15 cm、离底座约 15 cm 的安全观察区。
- 树莓派要求钢球连续稳定 6 帧后，三个电机依次试动 0.5°并返回，自动建立
  `(画面 x、画面 y、钢球半径)` 对三关节增量的局部矩阵。
- 第一阶段只把钢球对到画面中心；网页人工确认后第二阶段才沿相机轴下降。
- 每条相对命令任一关节不超过 0.5°，从人工观察位累计不超过 ±25°。
- 单字节 `!` 是低延迟急停；连续丢失钢球、矩阵不可用、回程偏差或角度超限
  都会自动急停。
- 当前到达目标半径后只报告 `READY_TO_GRAB`，尚未控制电磁铁。

完整协议、树莓派运行方法、网页入口和第一次方向标定见
[VISION_SERVO_README.md](VISION_SERVO_README.md)。机械模型尺寸见
[docs/MECHANICAL_MODEL_REPORT.md](docs/MECHANICAL_MODEL_REPORT.md)。

## 构建和烧录

CCS 导入本目录后构建 Debug 配置，烧录：

```text
Debug/26_stepper_multi.out
```

仓库中的该文件已经用 TI Arm Clang 4.0.4 LTS 编译完成。旧的无视觉按键测试
说明仍保留在 `IK_DEMO_TEST.md`，但正式调试优先使用网页端逐帧视觉模式。
