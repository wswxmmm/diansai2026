# 任意低位钢球视觉自标定

## 目标

摄像头竖直向下，并与电磁铁吸附中心同轴。系统不要求每次开机回到精准关节
零位，只要求操作者把末端放在无碰撞的低位观察区：离地约 10～15 cm、到底座
水平距离约 15 cm，并保证钢球出现在画面内。

## 两阶段工作流程

1. 网页只预览，黄色圆表示单帧候选。
2. 同一钢球连续稳定 6 帧后显示绿色圆。
3. 点击“① 自标定并对中”。MCU 进入相对模式，三个关节依次试动 0.5°并返回。
4. 树莓派建立三维局部视觉矩阵，随后每次最多命令 0.5°，只校正钢球圆心。
5. 连续 5 次确认位于 10 px 中心死区后，状态变为 `CENTERED` 并停止。
6. 操作者确认画面和机械结构安全，填写抓取目标半径，再点击
   “② 确认后垂直下降”。
7. 程序保持圆心不动，同时增大钢球半径；达到目标并稳定 5 次后状态变为
   `READY_TO_GRAB`。

每个关节从人工观察位的累计相对变化限制为 ±25°。连续 15 个原始帧找不到
钢球、校准矩阵秩不足、回程偏差超过 14 px、UART 超时或驱动命令失败均急停。

## 接线

| 用途 | 天猛星 | 对端 |
|---|---|---|
| Emm 电机总线 | UART0：PA10 TX、PA11 RX | 地址 1 底座、2 下臂、3 上臂 |
| Raspberry Pi | UART3：PB12 TX、PB13 RX | Pi 物理 10 脚 RX、8 脚 TX |

两块控制板只共地，不连接两端 3V3。UART 均为 115200、8N1。

## 新增 UART 协议

```text
RELATIVE START
RELATIVE STOP
JOG sequence motor1_mdeg motor2_mdeg motor3_mdeg
!
```

MCU 对单次 `JOG` 限制为 ±500 mdeg，对各轴累计限制为 ±25000 mdeg。

## 运行

烧录 `Debug/26_stepper_multi.out` 后，在树莓派运行：

```bash
cd /home/wxm/26_stepper_multi/raspberry_pi
python3 steel_ball_visual_servo.py
```

浏览器访问 `http://10.29.23.60:8000`。抓取半径默认 90 px，这只是保守占位值，
必须通过实际钢球和吸附距离标定；第一次下降应随时准备按急停或切断驱动电源。
