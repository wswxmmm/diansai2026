# 26_stepper_multi：三轴机械臂 + 树莓派钢球视觉伺服

本工程已经把三轴 Emm 闭环步进驱动、机械臂正/逆运动学，以及天猛星和
Raspberry Pi 的双向 UART 通信整合到同一固件中。

## 硬件分配

| 功能 | 天猛星外设和引脚 | 参数 |
|---|---|---|
| 三台 Emm 驱动器总线 | UART0，PA10 TX / PA11 RX | 115200，地址 1/2/3 |
| Raspberry Pi 通信 | UART3，PB12 TX / PB13 RX | 115200 |
| 板载按键 | PB21 | 仅在位姿已确认且视觉关闭时运行旧 IK 测试 |
| 板载 LED | PB22 | 移动时翻转；视觉到位后常亮 |

电机地址 1 是底座、地址 2 是下臂、地址 3 是上臂。最新实机测试确认底座和
下臂方向需要反相，上臂不反相；三轴传动均按 16 齿电机轮带 90 齿输出轮
（5.625:1）计算。

## 视觉控制安全逻辑

网页保留了两套控制方式：

- **标准姿态逆解（当前试验方案）**：手动摆成底座 0°、下臂竖直 90°、上臂
  水平 0°。钢球连续稳定 4 帧呈绿色后，网页锁定这一帧，用已知钢球直径和
  图像半径换算平面坐标。MCU 先确认标准数值位姿，再做一次逆解，将三个关节
  目标自动拆成“任一关节每段最多 5°”的同步小段连续执行。网页只需点击一次，
  电机速度为 10 RPM；默认只停在球顶上方 40 mm，不自动接触钢球。
- **任意低位自标定（备用方案）**：从任意安全低位对三轴逐一试动 1°并返回，
  建立局部视觉矩阵后对中；单次相对命令不超过 2°，累计不超过 ±25°。

三轴角度转脉冲统一按 16 齿电机轮带 90 齿输出轮，即 5.625:1、每机械轴
输出 1° 对应 50 个电机指令脉冲。单字节 `!` 是移动等待期间也会检查的急停。
当前程序尚未控制电磁铁。

标准姿态 `GOTO` 依次报告 `GOTO SOLVED`、若干条 `GOTO STEP` 和
`GOTO DONE`；网页保留最近 20 条 MCU 消息供诊断。

实机用 10 mm 钢球标定得到相机光轴到磁铁中心的局部偏移为：径向
`+67.5 mm`、切向 `-8.0 mm`。网页第一步补偿该偏移并停在球顶上方安全
高度；人工确认横向对准后，第二步保持 X/Y 不变并分段下降到默认 3 mm 间隙。
经用户确认机械结构可继续下转，上臂软件下限由 `-90°` 放宽为 `-110°`。

完整协议、树莓派运行方法、网页入口和第一次方向标定见
[VISION_SERVO_README.md](VISION_SERVO_README.md)。机械模型尺寸见
[docs/MECHANICAL_MODEL_REPORT.md](docs/MECHANICAL_MODEL_REPORT.md)。

## 构建和烧录

CCS 导入本目录后构建 Debug 配置，烧录：

```text
Debug/26_stepper_multi.out
```

仓库中的该文件已经用 TI Arm Clang 4.0.4 LTS 编译完成。旧的无视觉按键测试
说明仍保留在 `IK_DEMO_TEST.md`，当前调试优先使用网页端“标准姿态一次定点”。
