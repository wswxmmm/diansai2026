# 钢球视觉抓取改造方案

## 1. 当前工程能力

- MSPM0G3507 通过 UART0/PA10 单向控制三块 Emm 闭环步进驱动器。
- 驱动器地址为 1、2、3，使用 115200 8N1。
- 三条定位命令先进入驱动器队列，再用广播帧同步触发。
- 当前运动是相对位置模式，按 PB21 后三轴固定转动 36°。
- 当前默认 16 细分，即 3200 电机脉冲/圈；尚未计入减速比。
- 当前不读取驱动器反馈，没有机械零位、限位开关或关节绝对位置。

## 2. 推荐系统结构

```text
摄像头
  ↓ 图像
树莓派：钢球检测、像素到机械坐标标定、目标选择
  ↓ UART3：PB12/PB13，带序号的 PICK/STOP/HOME 命令
MSPM0：安全检查、逆运动学或关节目标执行、状态机
  ↓ UART0：PA10，Emm 多机同步总线
三台步进驱动器 → 三个机械臂关节
  ↓ GPIO + MOSFET
末端电磁铁
```

树莓派通信和电机总线必须使用两个独立 UART。UART0 保留给电机；UART3
的 PB12(TX)/PB13(RX) 用于树莓派，避免板载 CH340 和电机总线冲突。

## 3. 视觉坐标

如果摄像头固定、钢球位于固定平面，推荐在工作台放置至少四个已知坐标的
标定点，计算单应矩阵：

```text
[X, Y, 1]^T ∝ H [u, v, 1]^T
```

其中 `(u, v)` 是钢球框中心像素，`(X, Y)` 是机械臂基坐标系下的毫米坐标。
固定平面抓取时，钢球高度 `Z_ball` 由标定参数给出。

如果摄像头安装在机械臂末端，则不能直接使用固定单应矩阵，需要手眼标定和
分步对准流程，控制方案会不同。

## 4. 逆运动学

若机械结构为“底座旋转 + 大臂 + 小臂”的三关节机械臂，可先按以下形式解算：

```text
theta1 = atan2(Y, X)
r = sqrt(X^2 + Y^2) - tool_horizontal_offset
z = Z - base_height
D = (r^2 + z^2 - L1^2 - L2^2) / (2 L1 L2)
theta3 = atan2(±sqrt(1-D^2), D)
theta2 = atan2(z, r) - atan2(L2 sin(theta3), L1 + L2 cos(theta3))
```

必须先确认机械臂类型和零位定义。`|D| > 1` 表示目标不可达。正负解对应肘上/
肘下构型，应选取不碰撞且离当前姿态较近的一组。

角度增量转换为驱动器脉冲：

```text
pulses_i = abs(delta_angle_i) / 360
           * motor_pulses_per_rev
           * reduction_ratio_i
```

当前三轴均为 GT2 16T→90T，`reduction_ratio_i=5.625`。因此机械输出
一圈为18000脉冲，每度为50脉冲；原按键测试的320脉冲只会让机械轴
转动6.4°。

方向由角度增量符号和每轴 `DIRECTION_XOR` 共同决定。

## 5. 同步轨迹

现有同步广播可保留，但不能让三个关节始终使用相同 RPM。为使三轴同时到达，
应先选择公共运动时间 `T`，再按各轴脉冲距离计算速度：

```text
rpm_i = pulses_i * 60 / (motor_pulses_per_rev * T)
```

随后对速度、加速度、关节角和工作空间做限幅，再向三台驱动器排队并同步触发。

## 6. 电磁铁

电磁铁不能由 MCU GPIO 直接供电。推荐低边驱动：

```text
外部电源正极 ─ 电磁铁 ─ N 沟道逻辑级 MOSFET ─ GND
                         ↑ 栅极串联电阻接 MCU GPIO
电磁铁两端并联续流二极管，MCU 与电磁铁电源共地
```

MOSFET、电源和二极管规格必须按电磁铁额定电压和电流选择。建议增加保险丝，
并设置最大连续吸合时间，防止线圈过热。

## 7. 抓取状态机

```text
IDLE
 → HOME
 → MOVE_ABOVE_BALL
 → DESCEND
 → MAGNET_ON
 → LIFT
 → MOVE_TO_DROP_ZONE
 → MAGNET_OFF
 → RETURN_HOME
```

任一步收到 `STOP`、通信超时、目标越界或限位触发，都进入 `FAULT`，停止三轴；
故障处理时根据机械结构决定是否保持电磁铁吸合，避免钢球意外掉落。

## 8. 树莓派与 MCU 协议建议

原型阶段可以使用带换行的文本协议：

```text
HOME 17
PICK 18 125.4 -83.2 12.0
STOP 19
MAGNET 20 0
STATUS 21
```

第二个字段为递增序号，MCU 必须回复 `ACK <seq>`、`DONE <seq>` 或
`ERR <seq> <reason>`，防止重复执行抓取命令。正式比赛版本建议改为带长度、
序号和 CRC16 的二进制帧。

## 9. 实施前必须测量的信息

- 机械臂类型，以及三个电机分别控制哪个关节。
- 每段连杆轴心到轴心的长度 L1、L2 和末端偏置，单位毫米。
- 底座高度、钢球平面高度、放球区高度。
- 三轴机械零位、正方向、允许角度范围、减速比和细分数。
- 是否有原点/限位开关，Emm 驱动器是否可提供可靠到位反馈。
- 摄像头是固定在工作台还是安装在末端，以及相对机械臂基座的位置。
- 电磁铁额定电压、电流、质量和吸取距离。
