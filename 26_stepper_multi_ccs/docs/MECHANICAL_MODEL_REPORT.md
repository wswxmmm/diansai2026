# 机械臂 STEP/STL 几何解析报告

## 1. 数据与结论范围

- 模型目录中共有 **60 个 STL** 和 **2 个 STEP**。
- `robot_arm.step` 明确声明长度单位为 **毫米**（`SI_UNIT(.MILLI.,.METRE.)`）。
- 60 个 STL 中 59 个为闭合网格；`shank_calibrator_140mm.stl` 有非闭合边，但不影响其外形尺寸读取。
- 核心 STL 保留了装配坐标，因此可以把不同零件的孔轴直接对齐。`*_v2`、140 mm 版本、导轨和部分工具头被放在远离主装配的位置，属于备选/打印布局，不能直接并入当前装配位姿。

## 2. 坐标系和主要轴线

STEP 原坐标采用右手系。当前装配的主运动平面为 X-Z 平面，俯仰轴沿 Y。

| 名称 | STEP 中的轴线/中心（mm） | 方向 | 用途 |
|---|---:|---|---|
| J1 | X=99.989，Y=-49.005 | +Z | 底座回转（偏航）轴 |
| 输入驱动轴 | X=100.000，Z=23.500 | Y | 肩部两侧的电机/带轮输入轴投影位置 |
| A / J2 | X=100.000，Z=62.500 | Y | 两路平面运动的肩部公共输出轴 |
| B / J3 | X=11.685，Z=143.744 | Y | 下臂—上臂的肘部轴 |
| C / J4 | X=119.541，Z=196.348 | Y | 上臂—末端安装座的腕部轴 |
| 标准工具轴 | X=172.541，Y=-49.500 | +Z | 原装工具/夹爪竖直转轴；相对腕轴水平偏置约 53 mm |

STEP原坐标中肩轴A位于Z=62.5 mm，底座最低落地面约为Z=-67.7 mm。控制程序已经把底座落地面重标为Z=0，因此用于逆解的肩轴高度为约130.2 mm。

## 3. 主运动链尺寸

当前装配使用的是 **120 mm 版本**，不是目录中的 140 mm 备选版本。

| 杆段 | 两端 | 实测中心距 | 标称值 |
|---|---|---:|---:|
| 下臂 | A→B | 120.0005 mm | 120 mm |
| 上臂 | B→C | 120.0004 mm | 120 mm |
| 肩部短摇臂 | A→D | 40.0003 mm | 40 mm |
| 传动连杆 | D→E | 119.9999 mm | 120 mm |
| 上臂后端短边 | E→B | 模型特征约 40.16 mm | 40 mm（名义） |

其中 D≈(64.048, 44.965)，理想平行四杆的 E≈(-24.267, 126.209)。STEP 中邻近圆柱特征给出的 E≈(-24.381, 126.084)，与理想位置相差约 0.17 mm，属于具体孔/套/曲面特征的中心差异；运动学建模宜采用名义 40 mm。

当前导出姿态可用于检查电机零位：

- 下臂 A→B 对 +X 的绝对角约 **137.388°**。
- 上臂 B→C 对 +X 的绝对角约 **26.000°**。
- 短摇臂 A→D 对 +X 的绝对角约 **-154.000°**，与上臂方向相差约 180°，验证了平行四杆关系。

## 4. 机械结构判断

机械臂不是把第三台电机直接装在肘部的普通串联结构：

1. J1 绕 Z 轴转动整个上部机构。
2. 两路俯仰驱动集中在肩部，输出围绕 A/J2 的 Y 轴运动。
3. `lower_shank` 直接形成 A-B 的 120 mm 下臂。
4. `lever + pleuel + upper_shank` 构成名义为 40-120-40-120 mm 的平行四杆，把肩部另一驱动远程传到上臂；肘部不需要承受电机重量。
5. `triplate + pleuel_bend_lower + pleuel_bend_upper` 形成另一组姿态约束链，配合 `manipulator` 保持末端工具安装方向。

因此控制软件应使用“底座偏航 + 两个平面绝对杆角/平行四杆”的模型，并通过实机标定确定两台俯仰电机各自的正负号、减速比和零位。

## 5. 可用于逆解的名义模型

在底座旋转到目标方位后，令 A 为平面原点，下臂和上臂的绝对方向分别为 α、γ，则腕轴 C 的名义位置为：

```text
rC = 120*cos(α) + 120*cos(γ)
zC = 120*sin(α) + 120*sin(γ)
```

若直接使用STEP原坐标，全局高度需加62.5 mm；当前控制坐标以底座落地面为Z=0，因此全局高度加130.2 mm。底座偏航角由目标点在基座水平面的方位角得到。该公式给出几何杆角；将杆角换算为两个肩部步进电机角度时，还要加入平行四杆的方向关系以及齿轮/同步带传动比。

原装标准工具竖轴相对腕轴 C 在当前姿态下约沿 +X 偏置 **53 mm**。磁吸头真正的 TCP 还要加上磁铁安装后的水平偏置和竖直长度。

## 7. 备选结构和附件

- `shank_calibrator_120mm` 与 `shank_calibrator_140mm` 是两种杆长校准件。
- `shank_pleuel_140mm` 下包含完整 140 mm 加长臂版本；不能与当前 120 mm 参数混用。
- `dual_manipulator_support` 是双末端支撑改型。
- `rail_stl` 是独立直线导轨组件：2020 型材模型为 **150×20×20 mm**，滑台板为 **134.6×68×24 mm**。如果装上，它会增加一个直线自由度，需要单独标定行程和零位。
- `toolheads_stl` 中包含夹爪、舵机夹爪、笔架、挤出器等工具头，但没有明确命名或完整建模的电磁铁。
- 控制箱主体约 **70×139×60 mm**，不参与机械臂逆解。

## 8. 驱动代码中已确认的参数

从 `multi_motor_config.h`、`emm_multi_motor.c` 和 `empty.syscfg` 可以确认：

| 参数 | 当前值 |
|---|---:|
| 驱动器协议 | Emm UART 协议 |
| 闭环方式 | 编码器闭环在每块 Emm 驱动器内部完成 |
| UART | UART0，PA10 TX / PA11 RX，115200，TTL |
| 驱动器地址 | 1、2、3 |
| 电机基本步距 | 1.8°，200 整步/圈 |
| 细分 | 16 |
| 命令脉冲数 | 3200 脉冲/电机轴圈 |
| 默认测试速度 | 100 RPM |
| 默认加速度参数 | 10（Emm 0～255 参数） |
| 测试位移 | 相对 36°，320 脉冲 |
| 方向修正 | 1号=0，2号=反向，3号=0 |

三个输出大轮的 STL 外径约56.79 mm，齿形分析均得到90个周期，对应GT2-90T。实机三台电机均已确认安装16齿小轮。因此底座、下臂和上臂的机械减速比均为 **90:16=5.625:1**（电机转5.625圈，机械输出转1圈）。在3200脉冲/电机圈设置下：

- 每个机械输出圈：18000脉冲。
- 每个机械输出度：50脉冲。
- 电机轴100 RPM时，关节输出约17.778 RPM，即约106.667°/s。
- 原测试命令320脉冲对应电机轴36°，实际关节输出为6.4°。

三轴机械正方向已确认为逆时针。实机下降测试确认2号下臂需要方向异或，而3号上臂不需要方向异或。

当前三块驱动器共用 PA10 单向发送，驱动器 TX 没有接回 MCU。闭环可以在驱动器内部修正电机失步，但 `g_multiLastOperationOk` 只代表 UART 帧成功发出，不代表机械臂已经到位。要读取位置或报警，需要改成 RS485 多机总线，或者为每块驱动器提供独立/可复用的安全回读通道。

## 9. 当前采用的临时默认值

所有占位参数集中在 `robot_arm_config.h`。实体装配已经确认：**地址1=底座、地址2=下臂、地址3=上臂**，三轴均为5.625:1减速且逆时针为机械正方向。程序上电参考姿态由用户指定为下臂竖直向上90°、上臂水平向外0°；STL导出的137.388°/26.000°只用于核验模型，不再作为程序启动角。其余尚未实测的量仍使用临时值：磁铁安装长度暂按30 mm，摄像头外参暂为单位变换。机械限位检查默认关闭，避免未经测量的范围被误当成安全限位。

## 10. 仍需实物提供/测量的量

仅靠当前模型不能可靠得到以下参数：

1. 电磁铁吸附面的直径、厚度和重量。
2. 电磁铁吸附中心相对标准工具轴或腕轴 C 的三维偏置，尤其是吸附面到工具安装面的竖直距离。
3. 三轴的上电零位。传动比已经确认为5.625:1，驱动器侧为3200脉冲/电机轴圈，折算到机械输出为18000脉冲/圈。
4. 各关节机械限位角以及线缆允许的安全范围。
5. 摄像头相对机械臂基座的外参和钢球中心的高度基准。

这些量补齐后，模型已经足够建立钢球坐标到三台步进电机目标步数的完整解算链。
