# 天猛星 MSPM0G3507 MOS 开关模块工程

本工程用于驱动图片中的“高电平有效”MOS 开关模块。默认行为是：**按住天猛星开发板的 B21 按键时负载通电，松开时立即断电**；板载 PB22 LED 同步显示负载状态。

## 工程配置

- 开发板：立创·天猛星 TMX-MSPM0G3507
- IDE：TI Code Composer Studio Theia
- SDK：MSPM0 SDK 2.10.00.04
- SysConfig：1.26.2
- MOS 控制输出：PA14，高电平有效，上电默认低电平
- 用户按键：PB21，按下为低电平
- 状态 LED：PB22，高电平点亮

## 接线

### 单片机侧（三针控制排针）

| 天猛星 | MOS 模块 |
| --- | --- |
| PA14 | 信号端 `SIG` / `IN` / `S` |
| GND | 控制端 `GND` / `-` |

第三个未标为信号或 GND 的针脚不需要连接。请以你手中模块 PCB 丝印为准，不要只按排针的左右位置判断。

### 负载和 5V 电源侧（螺丝端子）

按图片上的极性连接：

- 5V 电源正极接模块电源输入 `+`，负极接电源输入 `-`。
- 电磁铁正极接负载输出 `+`，负极接负载输出 `-`。
- 天猛星 GND、MOS 控制端 GND 和 5V 电源负极必须共地。
- 负载电流不要从开发板的 5V/3V3 引脚取电，应使用容量足够的独立 5V 电源。

> 电磁铁属于感性负载。若模块没有板载续流保护，请在电磁铁两端并联续流二极管：二极管阴极接电磁铁正极，阳极接电磁铁负极。还要确认模块和电源的额定电流高于电磁铁工作电流。

## 导入与编译

1. 打开 CCS，选择 `File -> Import Project(s)`。
2. 选择本目录的 `27_MOS_SWITCH.projectspec`。
3. 确认安装/选择 MSPM0 SDK 2.10.00.04 与 SysConfig 1.26.2，然后编译。
4. 工程模板默认选择 XDS110；若使用仓库其他工程相同的 J-Link，请在工程属性中把连接改为 `SEGGER J-Link`。
5. 下载程序后，先不接电磁铁，用万用表检查 PA14：松开 B21 时约 0V，按住时约 3.3V。

## 在其他程序中控制

`mos_switch.h` 提供以下接口：

```c
MOS_Switch_On();          /* 吸合 */
MOS_Switch_Off();         /* 释放 */
MOS_Switch_Set(condition);/* 按条件控制 */
```

如果要改用其他 GPIO，请打开 `empty.syscfg`，把 `MOS_CTRL -> CONTROL` 的引脚从 PA14 改为所需引脚并重新编译。
